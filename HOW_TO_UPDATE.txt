THE HANDYMAN — INVOICE PDF UPDATE

1. Back up your accounting data from the app first.
2. Extract this ZIP.
3. Replace index.html in the root of your GitHub repository with the index.html in this folder.
4. Keep favicon.png, apple-touch-icon.png and icon-512.png in the repository root as before.
5. Commit the changes and wait for GitHub Pages to update.
6. Open the site in Safari, open an invoice, tap Create PDF, then Share PDF. This creates a real PDF file and opens the iPhone share sheet when supported. The PDF library loads from a CDN, so an internet connection is needed.

This has not been tested on your iPhone.
